AIT News Publisher

AIT News Publisher is the in-house publishing tool for the AIT YouTube channel. It runs on our own server and publishes only to that one channel, which we own.

What it does

  • Uploads the channel's news videos (Shorts and the daily bulletin) to YouTube.
  • Sets the thumbnail for each uploaded video.
  • Updates the title and thumbnail of the channel's own 24/7 live stream so they match the current top story.
  • Reads the channel's own basic statistics (subscriber and view counts) for an internal status page.

Who uses it

The tool is used only by the AIT channel team. It is not offered to the public, and it never signs in to, reads from or posts to anyone else's YouTube account.

Google data

The tool uses the YouTube Data API through Google sign-in (OAuth). How we handle that data is described in our Privacy Policy. Use of the tool is covered by our Terms of Service.
